## Relaciones de Conmutación

```
[L², Lz] = 0  →  Coherence y Nivel conmutan (pueden conocerse simultáneamente)
[Lx, Ly] ≠ 0  →  Autonomía y Coordinación NO conmutan (incertidumbre)
[Ĥ, L²] = 0   →  Hamiltonian y Coherence conmutan (el bus preserva la pureza)
[Ĥ, Lz] ≠ 0   →  El bus PUEDE cambiar el nivel de un agente (N1→N2, etc.)
```
