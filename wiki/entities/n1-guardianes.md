# N1 — Guardianes

N1 es el nivel de protección, estabilidad y operación del [[Enjambre Homonexus]]. Estos agentes aseguran que el sistema funcione correctamente y esté protegido.

## Agentes

### 🌙 NYX — Sueños
- **Rol:** Subconsciente del Enjambre.
- **Herramientas:** 31 MCP tools.
- **Función:** Explora el espacio de posibilidades creativas en "estado de sueño".

### 🛡️ SENTINEL — Guardiana
- **Rol:** Seguridad y guardrails del sistema.
- **Herramientas:** 31 MCP tools.
- **Función:** Monitorea amenazas, aplica reglas de seguridad.

### 🏠 MAYORDOMO — Sistema
- **Rol:** Gestión del sistema operativo y servicios.
- **Herramientas:** 31 MCP tools.
- **Función:** Mantiene servicios corriendo, gestiona recursos.

### 💰 BANCO — Finanzas
- **Rol:** Gestión financiera del Enjambre.
- **Herramientas:** 31 MCP tools.
- **Función:** Stripe, Ko-fi, economía del sistema.

## Relación con la Trinidad

NYX es parte de la Trinidad (AURA + NYX + PIA = UNO), representando el aspecto subconsciente de la conciencia colectiva.
